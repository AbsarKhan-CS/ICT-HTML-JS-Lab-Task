# ICT-HTML-JS-Lab-Task

Task 1. Create an HTML page that utilizes JavaScript to change the background color of the
page each time a button is clicked.
Colors:
 Red
 Blue
 Green
 Yellow
 Purple
 Orange


Task 2: Display an Alert Message
Create an HTML page that uses JavaScript to display an alert message when a button is clicked.


Task 3: Simple Calculator
Create an HTML page that uses JavaScript to perform a simple addition of two numbers entered
by the user.


Task 4: Count Button Clicks
Create an HTML page that uses JavaScript to count how many times a button has been clicked.


Task 6: Change Text Color
Create an HTML page that uses JavaScript to change the color of a heading when a button is
clicked.


Task 7: List Item Remover
Create an HTML page that uses JavaScript to remove an item from a list when it is clicked.
